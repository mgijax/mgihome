September 21, 2026
Mouse strain genes have been updated from Ensembl release 116
Mouse strain genome sequence data and annotations for assembled strain genomes other than the reference mouse strain (C57BL/6J) have been updated from Ensembl release 116. Where possible, strain genes are associated with MGI's canonical mouse genes using cross-references found in the strain gff3 files. These cross-references include C57BL/6J Ensembl or NCBI gene IDs, MGI gene IDs, or in some cases mouse gene nomenclature. The set of strain genes associated with an MGI gene can be found in the Strain Comparison section on Gene Detail pages. The Ensembl 116 strain gene gff3 files do not cross-reference preexisting strain genes established by the Wellcome Trust Sanger Institute's Mouse Genomes Project (MGP). Therefore, our strain gene load maintains legacy MGP ID-to-MGI associations for MGI genes that have associated strain genes from Ensembl 116. Users can search MGI by legacy MGP IDs to find the associated MGI genes from the previous Mouse Genome Project strain gene load. These legacy MGP IDs are also included in the updated strain gene gff3 files, which we make available for download. For more information on the new strain gene load from Ensembl 116, see: README.txt.
July 27, 2026
Allele tab quick search enhancements
The Quick Search Alleles result tab now includes Synonyms, Molecular Mutations, and Attributes with new filters added for Molecular Mutation, Attribute and Collection. Quick Search result download files still include genomic location.
New IMPC Molecular Note Load for CRISPR Alleles
MGI has implemented an "Allele Molecular Note Load" to import template-based mutation descriptions for over 6,500 endonuclease-mediated (CRISPR) alleles produced by members of the International Mouse Phenotyping Consortium (IMPC). The load associates specific molecular features (including details on the Production Center, Endonuclease Type, Guide Sequences, Genome Build, Deletion/Insertion Size and Location) with the corresponding Allele record in MGI. New Molecular IMPC notes are loaded weekly and are displayed in the "Mutation details" section of the MGI Allele Detail page.
To view an example of an automated Molecular IMPC Note, visit the Chac1em1(IMPC)Bay allele. To access further information about this allele, follow the link to the corresponding IMPC Gene page. To view the location of CRISPR guides, aligned FASTA sequence, and calculated CRISPR deletion in a genome context, follow the link to the corresponding IMPC Genome Browser page.
To access the entire set of CRISPR alleles that have obtained a Molecular IMPC Note, click the link for the Molecular Note Load Reference J:384794, displayed at the end of the note.
April 27, 2026
More new features for GXD
  • Gene cart added to the Tissue x Gene Matrix. A gene cart has been added to the Tissue x Gene Matrix tab of the expression search results. Previously, users could only filter by genes shown on the matrix page they were viewing. Now, with the new gene cart, they can page through the results, selecting genes for filtering from multiple pages.
  • Filter expression results by sex. Users can now filter expression search results to include only data derived from specimens for which the authors specified the sex. In addition, a column displaying the sex of the specimen has been added to the Assay Results tab of the expression search results.
  • Expanded batch search options. Gene list searches performed using GXD Batch Search can now be limited to current mouse symbols and synonyms. Previously, symbol and synonym searches included those of homologs as well. This new input option has also been added to the MGI Batch Query.
February 02, 2026
New features for GXD
  • Antibody summaries are now available in the Molecular Reagents section of gene detail pages and in the Curated Data section of reference detail pages. These summaries include the number of publications that have used each antibody, making it easier to identify commonly used ones.
  • Additional colors have been added to the Tissue x Stage and Tissue x Gene matrices in the GXD query results summary, making it easier for users to distinguish the number of annotations represented in each cell.
  • Enhanced interactivity between GXD and Morpheus. Results from GXD RNA-seq data searches can be forwarded to Morpheus, the Broad Institute's heat map visualization and analysis tool. Now, after performing analyses in Morpheus, users can select genes of interest and retrieve GXD's multi-tabbed expression summaries for these genes, which include both classical and RNA-seq results. Additional types of information for these genes can be accessed by using buttons on the Genes tab to forward the gene list to either the MGI Batch Query or MouseMine. MouseMine also offers tools for enrichment analysis.
